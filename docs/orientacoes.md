# Orientações do Trabalho

## 1. Introdução

Sua equipe de Ciência de Dados atua em uma operadora de pagamentos e precisa identificar fraudes e perfis de consumo em um banco de dados sem rótulos.

> **Atenção:** Cada grupo receberá uma base de dados exclusiva. Embora todas simulem transações de pagamento, cada base possui características próprias.

O objetivo é analisar a base recebida, selecionar e justificar os algoritmos mais adequados vistos na disciplina e apresentar os resultados.

## 2. Artigo

O artigo (de até 8 páginas incluindo referências, duas colunas) deve conter:

1. **Introdução:** Análise exploratória das características específicas da base do grupo e etapas de pré-processamento (escala, outliers, dados ausentes).
2. **Metodologia:** Escolha e justificativa técnica de pelo menos 3 abordagens distintas. Deve-se justificar a escolha dos algoritmos com base no perfil da base do grupo.
3. **Resultados e Discussão:** Gráficos com redução de dimensionalidade, métricas de validação e análise dos ruídos/clusters.
4. **Conclusão:** Tradução dos achados técnicos em ações práticas contra fraudes para a empresa.

Coloque a parte prática (código) no GitHub e faça a referência (o link) no próprio artigo.

## 3. Apresentação em Aula

**15 minutos MÁXIMO** de apresentação por grupo. Apresentar a visão geral do pipeline, justificativa das escolhas técnicas, principais gráficos e conclusões.
